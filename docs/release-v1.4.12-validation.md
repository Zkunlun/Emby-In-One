- GitHub Actions 正式 CI（全量 Go/vet/构建）以及六架构 Release 资产须以相应实际工作流结果为准；不能用上述定向回归代替。

## 用户实机验收及已知问题

用户确认除下列两项外其他功能实机验收通过，并明确选择**不修复，按 V1.4.12 正式发布**：

1. Hills Lite 首页的部分 `Items/Latest` 请求提示 `Upstream latest items request failed`。
2. Hills Lite 对部分特定来源媒体库的 `Items` 请求提示 `Upstream items request failed`，客户端可能显示 0 项或加载失败。

这些错误均为已知但未完成 EIO 与上游责任归因的兼容问题。不能据此断言服务器真实没有媒体，也不能宣称本次修复了上述现象。其他上游真实 500/502/524 或第三方弹幕扩展 404 不属于本次保证消除的异常。

## 升级与回滚

- 保留配置、全部数据文件、SQLite 状态、Token 及用户密码密钥；停止写入后进行一致性备份，避免只备份 DB 主文件而遗漏 WAL。
- DMIT 上已保留之前候选部署的完整回滚目录。若用户已产生新的观看进度，优先只回滚二进制，不默认用旧数据库覆盖新记录。
- 本次 GitHub 发布不等同于重新部署生产二进制；生产内部候选标识和 GitHub 正式版本注入标识可不同，但源码修复应一致。
