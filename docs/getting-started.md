# 首次使用

[项目主页](../README.md) · [文档索引](README.md) · [English](en/getting-started.md)

适用主线：V1.4.9。

## 先分清三个账户

| 账户 | 用途 |
| --- | --- |
| EIO 本地管理员 | 登录管理面板，管理来源/用户，也可在 Emby 客户端访问全部上游 |
| EIO 本地普通用户 | 客户端登录 EIO，只访问管理员授权的上游，使用本地独立观看状态 |
| 上游 Emby 账户或 API Key | 由 EIO 接入对应服务器；不代替本地面板或普通用户账户 |

先完成[安装](installation.md)，并准备自己有权使用且 EIO 能访问的上游。EIO 不附带媒体库资源。

## 第一步：登录管理面板

访问 `http://服务器IP:8096/admin`。Release/源码安装脚本首次显示 admin 的随机密码；手工安装则使用自己的初始配置。密码遗忘见[重置指南](operations.md#管理员密码重置)。

## 第二步：添加上游

在「上游节点」添加名称和 Emby URL，选择用户名/密码或 API Key 一种认证方式。用户名认证可空密码；Key 需要校验上游 `/Users/Me`。先用默认 proxy 模式建立接入，需要直连时再检查[播放取舍](playback-and-upstream.md#播放模式详解)。

客户端身份按上游要求选择 none、passthrough、infuse、hills、capyplayer 或 custom。没有限制时不必先设置固定身份预设。预设不代表所有客户端都已经验证。

保存后检查在线状态或 warning。用户名型 passthrough 尚无真实身份时会保存为 offline；用目标真实 Emby 客户端以 EIO 本地管理员登录一次，采集身份后会自动重试。管理面板登录未必提供这些头。详见[Passthrough 工作原理](playback-and-upstream.md#passthrough-模式工作原理)。

## 第三步：创建普通用户并授权

进入「用户管理」，新建本地用户并明确勾选可访问的上游。不选任何来源就是无上游访问权限。为自己/其他使用者配置账户；普通用户的观看状态与管理员直接读取上游的语义不同。

隐藏媒体库入口仅改变首页显示，不替代授权。密码、授权容量、单设备和解绑规则见[用户与权限](users-and-permissions.md)。

## 第四步：连接客户端

在 Emby 客户端添加服务器 `http://服务器IP:8096`，使用刚创建的 EIO 普通用户登录。使用自己的域名/反代时填实际 EIO 入口。不要把 /admin 路径当成客户端服务器地址，也不要将共享上游凭据当本地用户密码。

## 第五步：验证访问与播放

确认可见媒体来自授权范围，浏览一项内容并播放；有多版本时选择具体来源。proxy 需要 EIO 到推流源可达；redirect 还需要客户端直连源可达。

继续观看与自动完成需要客户端向 EIO 提供足够且可验证的控制上报，仅视频 GET/Range 不能证明看完。统计按在线授权来源的官方 Counts 累加，与合并后的作品数不同。相关问题见[排障](troubleshooting.md)及[统计说明](media-counts.md)。

## 管理面板入口一览

访问 `http://your-ip:8096/admin`，使用配置文件中的 admin 账户登录。

| 页面 | 功能 |
|------|------|
| **系统概览** | 在线服务器数、ID 映射数、存储引擎（SQLite） |
| **上游节点** | 添加/编辑/删除/重连服务器，使用上下按钮调整顺序；显示已授权普通用户数并配置“同播数量限制” `maxConcurrent` |
| **用户管理** | 创建、编辑、启用/禁用、删除普通用户，可视化配置可访问服务器 |
| **网络代理** | HTTP/HTTPS 代理池管理，支持一键连通性测试 |
| **全局设置** | 系统名称、默认播放模式、管理员账户、超时与宽恕期配置 |
| **运行日志** | 实时日志查看，支持级别筛选（ERROR/WARN/INFO/DEBUG）、关键词搜索、下载原始日志文件、清空日志 |

> 管理面板侧边栏底部显示当前运行版本号。对于 `spoofClient: passthrough` 的新增/编辑，如果当前没有已捕获的客户端身份，管理 API 仍会保存配置，但会返回 warning，并把该上游保留为 offline，等待真实客户端登录后自动重试。



管理 API 单列在[API 参考](admin-api.md)，日常更新、日志及 SSH 菜单见[运维](operations.md)。
