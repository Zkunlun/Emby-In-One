# V1.4.13 发布验证范围

## 修复与兼容边界

- 基于 V1.4.12，针对所有多上游作品统一修正 Shows/Seasons、Shows/Episodes 的并发聚合、慢源拖延、真实空结果与部分/全部失败区分、异常 HTTP 200 结构，以及全局超时等待边界。不存在针对特定剧名、媒体库或上游 ID 的例外。
- 普通用户季级 UnplayedItemCount 根据完整可见剧集及本地进度计算，额外查询最多等待 2.5 秒；不完整时省略字段而不是猜测 0。PlayCount、已观看、进度保持 EIO 用户隔离，不复制共享上游账号的个人状态。
- 客户端要求 Fields=Path 时按真实源条目补全，不伪造媒体源；合并确认同一作品时保留已知真实制作年份，不混合不同来源的父子 ID 和集数。
- 既有媒体授权、播放路由、SQLite 模式及每源 5000 条候选限制不变。草稿 PR #3（同上游多 Series/Season 配对）尚未验收，不属于本次发布。

## 工程与实机验证

- Windows Go 定向测试涵盖旧的季/集/映射/观看状态/媒体源合同和新增的慢源、快空慢非空、部分失败、全部失败、异常结构及全局超时边界。新用例 RED→GREEN 后定向回归通过。
- Linux/amd64 使用 Go 1.23.12 CGO 构建测试候选 phase5-rc-37bdfd2 成功；DMIT 使用独立配置/数据库/系统服务与正式 EIO 隔离，测试 HTTPS 及认证边界通过，用户报告 Hills Android 最终实机验收完成、无问题。
- Windows go test ./... 一次运行达到 900 秒执行上限，未取得后端完整回归结果，不得宣称全量回归通过。GitHub Actions 的普通全量测试、vet、六架构静态编译及 SHA256 资产应单独以实际日志判断。
